# Numerical outputs

five_disease_revision/ contains reconstructed cohort-level and country-year tables. revised/ contains model coefficients, sensitivity results, transmission results, age-structured mechanism summaries, external-validation tables, the EU/EEA measles-resurgence outputs and fitted R model objects. robustness_case_models/ contains the released robustness-model results.

Publication figures, manuscript tables and internal diagnostic/audit products are maintained outside this public release. The numerical files here are the reproducibility interface for the released scripts.
