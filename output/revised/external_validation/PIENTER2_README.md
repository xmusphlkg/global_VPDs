# PIENTER2 mumps age profile

This file transcribes the PIENTER2 column of Table 1 in the Dutch national mumps serosurveillance report ([PMC3592917](https://pmc.ncbi.nlm.nih.gov/articles/PMC3592917/)). The survey was conducted in 2006–2007. The nationwide sample contained 6,383 specimens and the low-immunization-coverage sample contained 1,517 specimens. The published table reports age-stratified mumps IgG positivity, sample size and 95% confidence intervals. Mumps antibody concentration was measured with a fluorescent bead-based multiplex immunoassay using the Jeryl Lynn vaccine strain; seropositivity used a threshold of 45 RIVM units/ml.

Rows cover the model-relevant ages 5–14 as single-year estimates, plus wider age bands. The 75–79-year sample denominator is absent in the published table; the row is retained with `sample_n=0` for transparent transcription and should be omitted from weighted calculations. PIENTER2 includes a national sample and an oversampled low-coverage sample, so pooled estimates require the study weights. This table is an aggregate mumps calibration layer; assay units have no international standard and antibody positivity has no validated protection correlate.
