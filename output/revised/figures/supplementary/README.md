# Supplementary Figures

Supplementary figures are rendered as 600-dpi PNG and Cairo PDF files. Their
panel source tables are in `output/revised/source_data/figure_redesign/`.

Render from the repository root:

```bash
Rscript scripts/05_figures/render_supplementary_figures.R
```

The active set contains nine supplementary figures: S1 paired sensitivity,
S2 cohort-reconstruction robustness, S3 Bayesian input audit,
and S4–S8 country-specific annual trajectories for measles, rubella, pertussis,
diphtheria and mumps, respectively. Each of S4–S8 has ten country facets and
four history-by-duration scenarios, using the Figure 3a colours. Lines show
posterior means and ribbons central 95% posterior intervals for expected
annual reports over 2014–2023; y axes are independently log-scaled by country.
The intervals exclude observation noise and uncertainty in fixed nuisance inputs.
Mumps uses the all-MCV proxy; Indonesia and Pakistan use the shared disease
posterior without country-specific observed mumps reports.

Render only the country trajectories with:

```bash
Rscript scripts/05_figures/render_supplementary_figures.R --s4-s8-only
```

Their source tables are `FigureS4_a.csv` through `FigureS8_a.csv`, each with
400 rows (ten countries × four scenarios × ten years).

S9 contains recipient-age and source-age marginal gains from the full contact operator in Figure 5a. It is regenerated by the full supplementary renderer or `render_main_figures.R --figure4-only`.
